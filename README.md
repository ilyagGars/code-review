## 1. Задание 1 — Возраст

### 1. Код из задания

```python
def can_buy(age):
    if age > 18:
        return True
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция должна принимать возраст и возвращать `True`, если человеку 18 лет или больше. Если возраст меньше 18 лет, должна возвращаться `False`.

#### Что код делает на самом деле

В коде используется условие:

```python
if age > 18:
    return True
```

Из-за этого возраст ровно 18 лет не проходит проверку. Также при возрасте меньше 18 функция ничего не возвращает.

#### Несоответствия

1. Используется `>` вместо `>=`.
2. Нет `return False` для возраста меньше 18.

#### Вердикт

**Отклонить**

#### Что исправить

Нужно изменить условие на `age >= 18` и добавить возврат `False`.

### 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

## 3. Задание 3 — Скидка

### 1. Код из задания

```python
def final_price(price):
    if price > 1000:
        return price - 10
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция должна принимать цену. Если цена 1000 или больше, должна применяться скидка 10%. Если цена меньше 1000, цена должна остаться без изменений.

#### Что код делает на самом деле

В коде используется условие:

```python
if price > 1000:
    return price - 10
```

При цене ровно 1000 условие не выполняется. При цене больше 1000 из неё просто вычитается 10, а не 10 процентов. Также при цене меньше 1000 функция ничего не возвращает.

#### Несоответствия

1. Используется `> 1000` вместо `>= 1000`.
2. Из цены вычитается 10 единиц вместо скидки 10%.
3. Нет возврата исходной цены, если она меньше 1000.

#### Вердикт

**Отклонить**

#### Что исправить

Нужно изменить условие на `price >= 1000`, правильно рассчитать скидку 10% и вернуть исходную цену, если она меньше 1000.

### 3. Исправленный код

```python
def final_price(price):
    if price >= 1000:
        return price * 0.9
    return price
```

## 4. Задание 4 — Оценка

### 1. Код из задания

```python
def is_pass(score):
    if score >= 50:
        print("зачёт")
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция должна принимать количество баллов и возвращать `True`, если результат 60 баллов или больше. Если баллов меньше 60, должна возвращаться `False`.

#### Что код делает на самом деле

В коде используется условие:

```python
if score >= 50:
    print("зачёт")
```

Получается, что зачёт ставится уже от 50 баллов. Кроме этого, код выводит текст на экран, а не возвращает значение `True` или `False`.

#### Несоответствия

1. Используется порог 50 вместо 60.
2. Используется `print()` вместо `return True`.
3. Нет `return False` для результата меньше 60.

#### Вердикт

**Отклонить**

#### Что исправить

Нужно изменить порог на 60, использовать `return True` и добавить `return False`.

### 3. Исправленный код

```python
def is_pass(score):
    if score >= 60:
        return True
    return False
```

## 5. Задание 5 — Температура

### 1. Код из задания

```python
def need_jacket(temp):
    if temp < 10:
        return False
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция должна принимать температуру и возвращать `True`, если температура ниже 10 градусов. Если температура 10 градусов или выше, должна возвращаться `False`.

#### Что код делает на самом деле

В коде используется условие:

```python
if temp < 10:
    return False
```

При температуре ниже 10 градусов функция возвращает `False`, хотя по ТЗ в этом случае нужно вернуть `True`.

Также при температуре 10 градусов и выше функция ничего не возвращает.

#### Несоответствия

1. При температуре ниже 10 возвращается `False` вместо `True`.
2. Нет `return False` для температуры 10 градусов и выше.

#### Вердикт

**Отклонить**

#### Что исправить

Нужно вернуть `True` при температуре ниже 10 градусов и добавить `return False` для остальных значений.

### 3. Исправленный код

```python
def need_jacket(temp):
    if temp < 10:
        return True
    return False
```
