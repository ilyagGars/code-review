## 1. Задание 1 — Возраст

### 1. Код из выданного материала

```python
def can_buy(age):
    if age > 18:
        return True
```

### 2. Рецензирование кода

#### Что требует ТЗ

Если возраст 18 или больше — `True`. Если меньше 18 — `False`.

#### Что не так в коде

При возрасте 18 код не сработает, потому что стоит `>`.

Также нет `False` для возраста меньше 18.

#### Несоответствия

1. `>` нужно заменить на `>=`.
2. Добавить `return False`.

#### Вердикт

**Отклонить**

#### Что исправить

Поменять условие и добавить `return False`.

### 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

## 3. Задание 3 — Скидка

### 1. Код из выданного материала

```python
def final_price(price):
    if price > 1000:
        return price - 10
```

### 2. Рецензирование кода

#### Что требует ТЗ

Если цена 1000 или больше — скидка 10%. Если меньше 1000 — цена не меняется.

#### Что не так в коде

При цене 1000 код не сработает, потому что стоит `>`.

Также из цены вычитается 10, а нужна скидка 10 процентов.

Для цены меньше 1000 нет результата.

#### Несоответствия

1. `>` нужно заменить на `>=`.
2. Нужно сделать скидку 10%.
3. Добавить возврат исходной цены.

#### Вердикт

**Отклонить**

#### Что исправить

Поменять условие, правильно посчитать скидку и добавить `return price`.

### 3. Исправленный код

```python
def final_price(price):
    if price >= 1000:
        return price * 0.9
    return price
```

## 4. Задание 4 — Оценка

### 1. Код из выданного материала

```python
def is_pass(score):
    if score >= 50:
        print("зачёт")
```

### 2. Рецензирование кода

#### Что требует ТЗ

Если 60 баллов или больше — `True`. Если меньше 60 — `False`.

#### Что не так в коде

В коде стоит 50, а нужно 60.

Также используется `print`, а нужно вернуть `True`.

Для результата меньше 60 нет `False`.

#### Несоответствия

1. 50 нужно заменить на 60.
2. `print()` нужно заменить на `return True`.
3. Добавить `return False`.

#### Вердикт

**Отклонить**

#### Что исправить

Поставить 60 и добавить возврат `True` или `False`.

### 3. Исправленный код

```python
def is_pass(score):
    if score >= 60:
        return True
    return False
```
