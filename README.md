## 1. Задание 1 — Возраст

### 1. Код из выданного материала

Файл: `task1_age.py`

```python
def can_buy(age):
    if age > 18:
        return True
    return False
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `can_buy(age)` должна:

- принимать возраст как целое число;
- возвращать `True`, если возраст 18 лет и больше;
- возвращать `False`, если возраст меньше 18.

#### Что код делает на самом деле

Код проверяет условие:

```python
age > 18
```

Это означает, что функция возвращает `True` только для возраста больше 18 лет.

Если возраст равен 18 годам, условие не выполняется и функция возвращает `False`.

#### Несоответствия

В ТЗ указано, что человек в возрасте 18 лет уже соответствует условию.

В коде используется условие `age > 18`, поэтому возраст 18 лет обрабатывается неправильно.

Должно использоваться условие:

```python
age >= 18
```

### 3. Исправленный код

Файл: `task1_age.py`

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

### 4. Вердикт

**Отклонить**

Причина: условие проверки возраста не соответствует ТЗ.

### 5. Что исправить

Заменить:

```python
age > 18
```

на:

```python
age >= 18
```
