## 1. Задание 1 — Возраст

### 1. Код из выданного материала

```python
def can_buy(age):
    if age > 18:
        return True
```

### 2. Рецензирование кода

#### Что требует ТЗ

Нужно проверить возраст. Если человеку 18 лет или больше, вернуть `True`. Если меньше 18 — вернуть `False`.

#### Что не так в коде

Здесь написано `age > 18`. Из-за этого при возрасте 18 условие не сработает.

Ещё нет `return False`, если возраст меньше 18.

#### Несоответствия

1. `>` нужно заменить на `>=`.
2. Нужно добавить `return False`.

#### Вердикт

**Отклонить**

#### Что исправить

Исправить условие и добавить `return False`.

### 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

## 3. Задание 3 — Скидка

### 1. Код из выданного материала

```python
def final_price(price):
    if price > 1000:
        return price - 10
```

### 2. Рецензирование кода

#### Что требует ТЗ

Если цена 1000 или больше, нужно сделать скидку 10%. Если цена меньше 1000, оставить её без изменений.

#### Что не так в коде

Здесь написано `price > 1000`, поэтому цена ровно 1000 не подходит.

Ещё из цены вычитается 10, а нужна скидка именно 10 процентов.

Если цена меньше 1000, функция ничего не возвращает.

#### Несоответствия

1. `> 1000` нужно заменить на `>= 1000`.
2. Нужно сделать скидку 10 процентов.
3. Нужно вернуть исходную цену, если она меньше 1000.

#### Вердикт

**Отклонить**

#### Что исправить

Исправить условие, правильно посчитать скидку и добавить возврат исходной цены.

### 3. Исправленный код

```python
def final_price(price):
    if price >= 1000:
        return price * 0.9
    return price
```
