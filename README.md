# Отчёт по ревью

## 1. Код из задания

```python
def can_buy(age):
    if age > 18:
        return True
    return False
```

## 2. Код ревью

### Что требует ТЗ

Функция `can_buy(age)` должна:

- принимать возраст как целое число;
- возвращать `True`, если возраст 18 лет и больше;
- возвращать `False`, если возраст меньше 18.

### Что код делает на самом деле

Код возвращает `True`, только если возраст больше 18.

При возрасте ровно 18 лет функция возвращает `False`.

### Несоответствия

В коде используется условие `age > 18`, хотя по ТЗ должно использоваться `age >= 18`.

### Вердикт

**Отклонить**

### Что исправить

Заменить условие `age > 18` на `age >= 18`.

## 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

## 2. Задание 2 — Пароль

### 1. Код из задания

```python
def is_strong(password):
    if len(password) > 8:
        return True
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `is_strong(password)` должна:

- принимать строку пароля;
- возвращать `True`, если длина пароля не меньше 8 символов;
- возвращать `False`, если длина пароля меньше 8 символов.

#### Что код делает на самом деле

Код проверяет условие:

```python
len(password) > 8
```

Это означает, что `True` возвращается только тогда, когда длина пароля больше 8 символов.

Если длина пароля ровно 8 символов, условие не выполняется.

#### Несоответствия

В ТЗ указано, что пароль длиной 8 символов должен считаться подходящим.

В коде используется условие `len(password) > 8`, поэтому пароль из 8 символов не проходит проверку.

Также в функции отсутствует `return False` для паролей длиной меньше 8 символов.

#### Вердикт

**Отклонить**

#### Что исправить

Заменить условие:

```python
if len(password) > 8:
```

на:

```python
if len(password) >= 8:
```

Также добавить `return False`.

### 3. Исправленный код

```python
def is_strong(password):
    if len(password) >= 8:
        return True
    return False
```
