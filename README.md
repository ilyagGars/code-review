## A1. Задание — Номер телефона

### 1. Код из выданного материала

```python
def make_phone(raw):
    try:
        text = str(raw)
        if "а" in text or "б" in text:
            return None
        number = "+" + text
        if len(number) > 11:
            return None
        return number
    except Exception:
        return None
    finally:
        print("проверка номера завершена")
        return number
```

### 2. Рецензирование кода

#### Что требует ТЗ

Нужно проверить номер телефона.

Если в номере 11 или больше цифр, нужно добавить `+` и вернуть номер.

Если номер неправильный, нужно вернуть `None`.

#### Что не так в коде

Код проверяет только буквы `а` и `б`. Другие буквы могут пройти.

Также длина проверяется вместе с `+`.

Ещё `return number` находится в `finally`, из-за этого может вернуться неправильный результат.

#### Несоответствия

1. Проверяются не все символы.
2. Неправильно проверяется длина.
3. `return number` в `finally` здесь не нужен.

#### Вердикт

**Отклонить**

#### Что исправить

Проверять, что в номере только цифры, правильно проверить длину и убрать `return` из `finally`.

### 3. Исправленный код

```python
def make_phone(raw):
    try:
        text = str(raw)
        if not text.isdigit():
            return None
        if len(text) < 11:
            return None
        return "+" + text
    except Exception:
        return None
    finally:
        print("проверка номера завершена")
```

## A2. Задание — PIN-код карты

### 1. Код из выданного материала

```python
def check_pin(raw):
    try:
        pin = raw
        if len(pin) >= 4:
            return "ok"
    except Exception:
        return "ok"
    finally:
        print("пин проверен")
        return "ok"
```

### 2. Рецензирование кода

#### Что требует ТЗ

PIN должен иметь 4 цифры.

Правильный PIN — `"ok"`.

Неправильный PIN — `"bad"`.

#### Что не так в коде

Код принимает PIN, если в нём 4 символа или больше.

Но нужно ровно 4 цифры.

Также код не проверяет, что это именно цифры.

При ошибке код возвращает `"ok"`, а должен `"bad"`.

В `finally` тоже стоит `return "ok"`.

#### Несоответствия

1. Нужно ровно 4 символа.
2. Нужно проверить цифры.
3. При ошибке должен быть `"bad"`.
4. В `finally` не нужен `return`.

#### Вердикт

**Отклонить**

#### Что исправить

Проверить цифры, длину PIN и убрать `return` из `finally`.

### 3. Исправленный код

```python
def check_pin(raw):
    try:
        pin = str(raw)
        if not pin.isdigit():
            return "bad"
        if len(pin) != 4:
            return "bad"
        return "ok"
    except Exception:
        return "bad"
    finally:
        print("пин проверен")
```
