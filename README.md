# Отчёт по ревью

## 1. Код из задания

```python
def can_buy(age):
    if age > 18:
        return True
    return False
```

## 2. Код ревью

### Что требует ТЗ

Функция `can_buy(age)` должна:

- принимать возраст как целое число;
- возвращать `True`, если возраст 18 лет и больше;
- возвращать `False`, если возраст меньше 18.

### Что код делает на самом деле

Код возвращает `True`, только если возраст больше 18.

При возрасте ровно 18 лет функция возвращает `False`.

### Несоответствия

В коде используется условие `age > 18`, хотя по ТЗ должно использоваться `age >= 18`.

### Вердикт

**Отклонить**

### Что исправить

Заменить условие `age > 18` на `age >= 18`.

## 3. Исправленный код

```python
def can_buy(age):
    if age >= 18:
        return True
    return False
```

## 2. Задание 2 — Пароль

### 1. Код из задания

```python
def is_strong(password):
    if len(password) > 8:
        return True
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `is_strong(password)` должна:

- принимать строку пароля;
- возвращать `True`, если длина пароля не меньше 8 символов;
- возвращать `False`, если длина пароля меньше 8 символов.

#### Что код делает на самом деле

Код проверяет условие:

```python
len(password) > 8
```

Это означает, что `True` возвращается только тогда, когда длина пароля больше 8 символов.

Если длина пароля ровно 8 символов, условие не выполняется.

#### Несоответствия

В ТЗ указано, что пароль длиной 8 символов должен считаться подходящим.

В коде используется условие `len(password) > 8`, поэтому пароль из 8 символов не проходит проверку.

Также в функции отсутствует `return False` для паролей длиной меньше 8 символов.

#### Вердикт

**Отклонить**

#### Что исправить

Заменить условие:

```python
if len(password) > 8:
```

на:

```python
if len(password) >= 8:
```

Также добавить `return False`.

### 3. Исправленный код

```python
def is_strong(password):
    if len(password) >= 8:
        return True
    return False
```

## 3. Задание 3 — Скидка

### 1. Код из задания

```python
def final_price(price):
    if price > 1000:
        return price - 10
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `final_price(price)` должна:

- принимать цену как число;
- если цена 1000 и больше — возвращать цену со скидкой 10%;
- если цена меньше 1000 — возвращать цену без изменений.

#### Что код делает на самом деле

Код проверяет условие:

```python
price > 1000
```

Если цена больше 1000, из неё вычитается число 10.

Например, при цене 1500 код вернёт 1490.

#### Несоответствия

В ТЗ указано, что скидка должна составлять 10%.

В коде из цены вычитается фиксированное число 10, а не 10 процентов.

Также условие `price > 1000` не учитывает цену ровно 1000, хотя по ТЗ скидка должна применяться при цене 1000 и больше.

Для цены меньше или равной 1000 функция также не возвращает исходную цену.

#### Вердикт

**Отклонить**

#### Что исправить

Нужно использовать условие `price >= 1000`.

Скидку нужно рассчитывать как 10% от цены.

Также необходимо вернуть исходную цену, если она меньше 1000.

### 3. Исправленный код

```python
def final_price(price):
    if price >= 1000:
        return price * 0.9
    return price
```

## 4. Задание 4 — Оценка

### 1. Код из задания

```python
def is_pass(score):
    if score >= 50:
        print("зачёт")
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `is_pass(score)` должна:

- принимать баллы как число;
- возвращать `True`, если баллов 60 и больше;
- возвращать `False`, если баллов меньше 60.

#### Что код делает на самом деле

Код проверяет условие:

```python
score >= 50
```

Если баллов 50 или больше, функция выводит на экран `"зачёт"`.

При этом функция не возвращает значения `True` или `False`.

#### Несоответствия

В ТЗ указано, что зачёт должен быть при результате 60 баллов и больше.

В коде используется условие `score >= 50`, поэтому зачёт получается уже при 50 баллах.

Также функция должна возвращать `True` или `False`, а код использует `print()` и ничего не возвращает.

#### Вердикт

**Отклонить**

#### Что исправить

Заменить условие `score >= 50` на `score >= 60`.

Вместо `print("зачёт")` функция должна возвращать `True`.

Для результата меньше 60 нужно добавить `return False`.

### 3. Исправленный код

```python
def is_pass(score):
    if score >= 60:
        return True
    return False
```

## 5. Задание 5 — Температура

### 1. Код из задания

```python
def need_jacket(temp):
    if temp < 10:
        return False
```

### 2. Рецензирование кода

#### Что требует ТЗ

Функция `need_jacket(temp)` должна:

- принимать температуру воздуха;
- возвращать `True`, если температура ниже 10 градусов;
- возвращать `False`, если температура 10 градусов или выше.

#### Что код делает на самом деле

Код проверяет условие:

```python
temp < 10
```

Если температура ниже 10 градусов, функция возвращает `False`.

При температуре 10 градусов или выше функция ничего не возвращает.

#### Несоответствия

Логика функции работает неправильно.

По ТЗ при температуре ниже 10 градусов функция должна возвращать `True`, а в коде возвращается `False`.

Также отсутствует `return False` для температуры 10 градусов и выше.

#### Вердикт

**Отклонить**

#### Что исправить

При температуре ниже 10 градусов нужно возвращать `True`.

Для температуры 10 градусов и выше нужно возвращать `False`.

### 3. Исправленный код

```python
def need_jacket(temp):
    if temp < 10:
        return True
    return False
```
